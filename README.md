# 个人作品集网站（React + Tailwind · 纯静态 · 可部署 GitHub Pages）

## 这是什么
一个展示你设计作品的单页网站。支持：
- 作品瀑布流浏览（图片 / 视频混排）
- 按分类筛选：场景 / 角色 / 3D / Sketch
- 左键点击作品 → 放大 / 进入详情页
- 详情页可左右滑动查看同一作品的多个版本（V1 / V2 …）
- 同一作品可同时有图片版本和视频版本，左右切换即可
- 参考图（ref）不出现在首页，只在详情页横向展示，且可再次点击放大
- 分类由**文件所在文件夹**决定，文件名只需写 V(版本) 与 ref(参考)
- `sketch` / `inspire` 用**网络图**展示（一幅图 = 一个发光节点，同名自动聚簇；支持滚轮缩放、中键拖动、悬停展开缩略图、点击进详情），且这两类**不进入 "All" 瀑布流**

> 你**不需要懂编程**。你只需要按下面的命名规则把素材放进 `assets` 对应文件夹，然后告诉我更新清单即可。

## 目录结构
```
webv2/
├─ index.html          网站主页面（打开这个就是网页）
├─ assets.js           作品清单（我负责生成，你不用手改）
├─ README.md           本说明
└─ assets/
   ├─ scene/           场景素材（图片或视频）
   ├─ character/       角色素材（图片或视频）
   ├─ 3d/              3D 作品（以图片或视频展示）
   ├─ sketch/          手绘 / 草图素材
   └─ inspire/         灵感 / 参考素材
```

## 命名规范（重要！按这个命名，网站才能自动识别）

**分类 = 文件所在的文件夹**，不需要前缀。文件名只需体现**版本**与**参考图**。

格式：
```
[作品名]_[版本号或参考].[扩展名]
```

| 组成 | 取值 | 含义 | 示例 |
| --- | --- | --- | --- |
| 作品名 | 你起的名 | 代表同一件作品 | `island` |
| 版本 | `_V1`、`_V2`… | 同一作品的不同版本，详情页可左右切换 | `_V1` |
| 参考图 | `_ref` | 依附于该作品的参考图（首页不显示） | `_ref` |
| 扩展名 | `.jpg/.png/.webp` → 图片；`.mp4/.webm/.mov` → 视频 | 决定显示为图片或视频 | `.jpg` |

### 举例
```
island_V1.jpg      → 「island」版本1（图片）
island_V2.mp4      → 「island」版本2（视频）—— 同一作品可图片/视频混排
island_ref01.png   → 「island」的参考图1
desert_V1.mp4      → 场景「desert」版本1（视频）
hero_V1.png        → 角色「hero」版本1（图片）
```

### 规则要点
- **放置位置**：放进 `assets/` 对应分类文件夹（scene / character / 3d / sketch），网站据此判断分类。
- 同一个「作品名」的 `_V1`、`_V2`… 会被自动归为同一作品的多个版本。
- 带 `_ref` 的图片会自动关联到同作品名的主图，只在详情页展示，可横向滚动、点击放大。
- `.jpg/.png` 显示为图片；`.mp4` 显示为视频。

## 使用流程（你只需两步）
1. 把图片 / 视频放进 `assets` 对应分类文件夹（scene / character / 3d / sketch），并按上面的命名规则命名。
2. 告诉我“更新清单”，我会帮你重新生成 `assets.js`。

然后把你改好的整个文件夹上传到 GitHub，开启 GitHub Pages，就能得到一个所有人可访问的网址。

---

## 本地预览
直接双击 `index.html` 即可浏览图片 / 视频作品。也可双击 `start_preview.bat` 用本地服务打开（自动选择一个端口并打开浏览器）。
